- Evidence and Findings
- workspace/src/webviewShell.js는 Kanban을 포함한 5개 탭 shell과 선택 상태 보존만 구현한다.
- Kanban 패널은 Work Unit 보드가 후속 Work Unit에서 구현된다는 빈 상태 문구만 표시한다.

- 현재 단위 테스트는 shell 구조·키보드 탐색·테마·전체 폭만 검증한다.

- 실행 중 Extension Development Host의 현재 화면과 파일 변경 반영 동작은 아직 관찰하지 않았다.
