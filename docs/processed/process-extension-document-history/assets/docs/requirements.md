# Codex Chat VS Code Extension 요구사항

## 1. 목적

OpenAI의 공식 Codex 채팅 UI를 대신해 사용할 수 있는, 개발자 중심의 단일
VS Code 확장을 제공한다. 사용자는 편집기를 벗어나지 않고 현재 workspace를
기준으로 Codex와 대화하고 실행 상태를 확인할 수 있어야 한다.

## 2. 제품 원칙

- 배포 단위는 VS Code 확장 하나뿐이다.
- 채팅이 제품의 주 기능이며 다른 도구는 채팅 흐름을 보조할 때만 포함한다.
- Extension Host가 Codex 프로세스, 파일 시스템, 영속 상태를 소유한다.
- Webview는 화면 표시와 사용자 입력을 담당하고 시스템 권한을 직접 갖지 않는다.
- 기존 Codex 인증과 사용자 설정을 재사용하며 별도 계정 체계를 만들지 않는다.
- 특정 웹 애플리케이션이나 실행 중인 외부 서버에 의존하지 않는다.

## 3. MVP 기능 요구사항

### FR-01. 채팅 열기

- Activity Bar 또는 명령 팔레트에서 채팅을 열 수 있어야 한다.
- 동일한 workspace에서 명령을 반복 실행해도 하나의 채팅 패널을 재사용해야 한다.

### FR-02. 세션 관리

- 새 세션을 만들고 기존 세션을 선택하거나 삭제할 수 있어야 한다.
- 세션별 메시지, 초안, 선택 모델, 추론 수준과 실행 상태가 섞이지 않아야 한다.
- VS Code를 다시 열거나 패널을 닫았다 열어도 완료된 대화가 복원되어야 한다.
- 실행 중 닫힌 세션은 복원 시 중단 상태로 명확히 표시해야 한다.

### FR-03. Codex 실행

- 현재 workspace root를 작업 디렉터리로 사용해야 한다.
- 새 대화를 시작하고 제공자가 발급한 세션 ID를 이용해 후속 대화를 재개해야 한다.
- 응답 텍스트와 실행 진행 상태를 스트리밍해야 한다.
- 실행 중인 요청을 취소할 수 있어야 한다.
- 실패 원인을 사용자가 이해할 수 있는 오류 메시지로 표시해야 한다.

### FR-04. 작성기

- Enter는 전송, Shift+Enter는 줄바꿈으로 동작해야 한다.
- IME 조합 중 Enter는 전송으로 처리하지 않아야 한다.
- 실행 중에는 전송 버튼이 취소 버튼으로 바뀌어야 한다.
- 이미지 붙여넣기, 미리보기, 개별 제거와 전체 제거를 지원해야 한다.

### FR-05. 실행 옵션

- 지원 모델과 해당 모델의 추론 수준을 선택할 수 있어야 한다.
- 빠른 실행 모드를 선택할 수 있어야 한다.
- 지원하지 않는 옵션은 Extension Host에서 거부하거나 안전한 기본값으로 정규화해야 한다.

### FR-06. VS Code 통합

- 활성 VS Code 테마의 색상 토큰과 글꼴을 사용해야 한다.
- 키보드만으로 주요 채팅 기능을 사용할 수 있어야 한다.
- 좁은 편집기 영역에서도 작성기와 메시지 내용이 잘리지 않아야 한다.

## 4. 품질 및 보안 요구사항

- Webview 메시지는 명시적인 allowlist와 입력 크기 제한으로 검증한다.
- Webview에는 nonce 기반 Content Security Policy를 적용한다.
- Codex 실행은 shell을 거치지 않고 인자 배열로 호출한다.
- 임시 이미지 파일은 전송, 제거 또는 패널 종료 후 정리한다.
- 세션 하나의 실패가 다른 세션 상태에 영향을 주지 않아야 한다.
- 핵심 상태 전이, 메시지 검증, 프로세스 adapter와 Webview protocol은 단위 테스트한다.
- 패키징된 VSIX에 실행에 필요한 파일만 포함되었는지 검증한다.

## 5. MVP 제외 범위

- 별도 로그인, 결제 또는 API key 관리 UI
- 브라우저용 채팅 애플리케이션
- 원격 협업 및 대화 공유
- Agent Factory artifact Editor, Kanban, Dashboard
- 다중 VS Code 확장으로 기능을 분리하는 구조
- MVP에서 지원 대상으로 명시하지 않은 운영체제용 Codex 바이너리 번들

기존 `workspace/` 구현은 `.backup/legacy-2026-08-29/workspace/`에 보존한다.
채팅 MVP에는 포함하지 않으며, 추후 필요한 기능만 단일 확장에 선택적으로 통합한다.

## 6. MVP 완료 조건

- 하나의 VSIX만 설치해 채팅을 열고 Codex 대화를 시작할 수 있다.
- 새 대화, 후속 대화, 스트리밍, 취소, 세션 복원과 이미지 첨부가 동작한다.
- 두 개 이상의 세션을 오가도 메시지와 실행 상태가 격리된다.
- 단위·통합 테스트와 VSIX 내용 검증이 통과한다.
- 수동 검증에서 밝은/어두운 테마, 좁은 화면, 키보드 입력을 확인한다.

## 7. 미결정 사항

- 최초 지원 운영체제 범위
- 확장 이름, command namespace와 Marketplace 식별자
- Codex CLI를 VSIX에 포함할지 시스템 설치본을 우선할지 여부
- 대화 보존 기간과 workspace별 최대 세션 수
- 백업된 Agent Factory Workspace 기능 중 다시 통합할 범위
