# Agent Factory Workspace

VS Code 에디터 영역에서 Agent Factory 작업공간을 여는 확장입니다.

다음 workspace 탭을 제공합니다.

- Dashboard
- Editor
- Kanban
- Context

명령 팔레트에서 `Agent Factory: Open Workspace`를 실행해 열 수 있습니다.

Editor는 canonical Intake, Specification 및 Work Unit의 공통 sectioned
구조를 탐색하고 읽기 전용 JSON 미리보기를 표시합니다. 지원되는 semantic
field 저장은 artifact별 Agent Factory manager를 통해 검증됩니다. Kanban은
Work Unit lifecycle을 표시하고 허용된 DnD 및 Move 전이를 제공합니다.
